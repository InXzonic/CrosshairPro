# CrosshairPro
🎯 Crosshair Pro (Windows)

Download : https://github.com/InXzonic/CrosshairPro/actions/runs/21091672397/artifacts/5163234334

Crosshair Pro is a lightweight Windows overlay software that displays a customizable crosshair at the center of your screen.
It is designed for FPS games and works on top of any application.

This software is:

Portable (no install required)

Adjustable in real time

Safe & stable

Built using Python + Tkinter

✨ Features
🔹 Crosshair Customization

Adjust Size

Adjust Thickness

Adjust Center Gap

Change Color (RGB sliders)

Supports any color (including pure black)

🔹 Crosshair Modes

Cross

Dot

Circle

🔹 Recoil Compensation

Enable / Disable with a button

Adjustable Recoil Strength

Smooth vertical recoil simulation

Automatically resets when disabled

🔹 Settings Management

Save Settings (overwrites previous settings)

Reset All (restores default values)

Only one profile is used (simple & clean)

🔹 UI & Behavior

UI always stays on top

Crosshair overlay is click-through

Closing the UI fully exits the program

No background services left running

🖥️ How It Works

A transparent fullscreen overlay is drawn

Crosshair is rendered at screen center

UI controls update the crosshair instantly

Recoil compensation shifts the crosshair slightly when mouse is clicked

🎮 How to Use (Step by Step)
1️⃣ Run the Program

Double-click crosshair_pro.py

Or run the .exe if built

You will see:

A control window (UI)

A crosshair at screen center

2️⃣ Adjust Crosshair

Use sliders in the UI:

Size → length of crosshair arms

Thickness → width of arms

Gap → distance from center

Red / Green / Blue → color

Changes apply instantly.

3️⃣ Change Mode

Use the dropdown:

cross

dot

circle

4️⃣ Recoil Compensation

Click Enable Recoil Compensation

Hold Left Mouse Button

Crosshair will move down smoothly

Adjust Recoil Strength slider

Click Disable Recoil Compensation to turn it off.

5️⃣ Save Settings

Click Save Settings

Your settings are saved to profiles.json

Next time you open the app, settings are restored

Saving again will overwrite the old settings

6️⃣ Reset All

Click Reset All

Everything goes back to default

Recoil compensation is disabled automatically

7️⃣ Exit Program

Close the UI window ❌

The overlay and program will exit completely
